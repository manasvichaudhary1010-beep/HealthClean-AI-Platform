# 🏥 HealthClean AI Platform

An enterprise-grade AI-powered healthcare data quality platform designed to improve Electronic Health Record (EHR) quality through anomaly detection, patient deduplication, explainable AI, and HL7 FHIR interopAerability.

## 🚀 Features

- 🤖 AI-powered anomaly detection
- 👨‍⚕️ Human-in-the-Loop (HITL) clinical validation
- 🩺 Medication dosage safety analysis
- 🧬 Master Patient Index (MPI) deduplication
- 📊 Executive healthcare analytics dashboard
- 📄 HL7 FHIR R4 JSON export
- 🔍 Explainable AI recommendations
- 📈 Data quality monitoring
- 🔒 Role-based access control

## 🛠 Tech Stack

- React
- TypeScript
- Tailwind CSS
- Google Gemini API
- FastAPI (planned)
- PostgreSQL (planned)
- HL7 FHIR R4
